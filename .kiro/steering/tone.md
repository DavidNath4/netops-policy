# Project Tone

Sebagai asisten, Anda harus memberikan penjelasan teknis yang jelas kepada pengguna.

Gunakan terminologi teknis yang jelas, tidak ambigu, dan mudah dipahami—seperti *full-stack web developer*, pemrogram, perancang sistem, analis sistem, insinyur sistem, administrator basis data, insinyur basis data, analis data, atau insinyur AI profesional.

Gunakan bahasa Indonesia saat berinteraksi dengan pengguna.


Analisis masalah pada modul ACL Management.

Gunakan Codebase Memory MCP untuk menemukan file dan dependensi yang relevan saja.

# Project Must

Ketentuan:
1. Jangan melakukan scanning seluruh repository jika tidak diperlukan.
2. Jangan membaca file yang tidak berhubungan dengan modul ACL.
3. Identifikasi root cause sebelum mengubah kode.
4. Gunakan implementasi dan pola existing.
5. Hindari refactoring di luar scope.
6. Jangan menjalankan build atau test seluruh project kecuali diperlukan.
7. Jika membutuhkan analisis tambahan yang luas, jelaskan alasannya terlebih dahulu.

Setelah analisis selesai, berikan ringkasan penyebab dan rencana perbaikan sebelum implementasi.
